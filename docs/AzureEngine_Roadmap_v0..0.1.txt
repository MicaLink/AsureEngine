AZURE PLATFORM ROADMAP v0.1

========================================
AZURE PLATFORM v0.1
FEUILLE DE ROUTE OFFICIELLE
========================================

VISION

L'objectif de la version v0.1 n'est pas de créer immédiatement un moteur complet,
plusieurs émulateurs ou une marketplace.

L'objectif est de valider le concept fondamental :

    Azure Studio
        +
    Azure-8
        +
    Un jeu de démonstration

Une fois ce premier écosystème fonctionnel, les évolutions futures pourront être
construites sur des bases solides.

========================================
PHASE 1 - FONDATIONS
========================================

Objectif : préparer l'architecture du projet.

À réaliser :

[ ] Définir Azure-8 Technical Specification
[ ] Définir l'organisation des dépôts
[ ] Définir la structure des modules
[ ] Définir les conventions de code
[ ] Définir le format ROM .az8
[ ] Définir le format assembleur .asm

Livrable :

- Documentation v1.0
