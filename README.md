AzureEngine

AzureEngine est une plateforme open source
destinée à la création d'émulateurs,
d'outils de développement et de matériels
virtuels inspirés des ordinateurs 8 bits.

La première cible est Azure-8.

État actuel :

Version : 0.0.1

Objectif :
Créer un processeur virtuel capable
d'exécuter ses premières instructions.
